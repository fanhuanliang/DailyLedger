# Publication history

This repository reconstructs the application development milestones from sanitized snapshots. Commit identities are generic and commit hashes differ from the private development repository. Original development dates are preserved. Personal data, operational credentials and private financial files are excluded.

The original repository and local data are maintained separately. The public repository has independent Git storage and must not be used as a financial backup. Deployments obtain private runtime settings and databases separately; later reviewed imports use the authenticated API/MCP bridge.
